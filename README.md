
# House Price Prediction Using Linear Regression

## Project Overview

This is a simple beginner-level machine learning project that predicts the price of a house based on its **square footage** using **Linear Regression**.

A small dataset is created using Python with two variables: square footage and house price. The data is divided into training and testing sets, and a Linear Regression model is trained to learn the relationship between house size and price.

The project also displays a regression line using Matplotlib.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Scikit-learn

## Machine Learning Model

**Linear Regression**

## Input Feature

**Square Feet**

## Target Variable

**House Price**

## Steps

1. Create the house price data using a Python DataFrame.
2. Separate the input feature and target variable.
3. Split the data into training and testing sets.
4. Train the Linear Regression model.
5. Display the model intercept and coefficient.
6. Enter square footage to predict the house price.
7. Visualize the training data, testing data, and regression line.

## Example

The user can enter a house size such as:

`2200`

The model then predicts the estimated house price based on the learned relationship between square footage and price.
